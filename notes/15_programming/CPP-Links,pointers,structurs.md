## Часть 1. Указатели

#### 1.1. Что такое указатель

Указатель — это переменная, которая хранит **адрес** другой переменной в памяти. Сам указатель занимает 8 байт на 64-битной системе (независимо от того, на что он указывает).

```cpp
int x = 42;
int* p = &x;   // p хранит адрес x
```

- `&x` — оператор взятия адреса.
- `*p` — оператор разыменования (получить значение по адресу).
- `p` — сам адрес.
- `&p` — адрес самого указателя.

Схематично:

```
переменная p         переменная x
+----------+         +----------+
| 0x7fff.. | ------> |    42    |
+----------+         +----------+
   адрес x              значение
```

#### 1.2. Объявление указателей

```cpp
int* p1;           // указатель на int
int *p2;           // то же самое, стилистически иначе
int * p3;          // тоже то же
int* p4, p5;       // ВНИМАНИЕ: p4 — указатель, p5 — просто int!
int *p6, *p7;      // оба указатели
```

Правило: `*` относится к переменной, а не к типу. Поэтому `int* p4, p5` создаёт `int* p4` и `int p5`.

Разные типы указателей:

```cpp
int*         pi;      // указатель на int
double*      pd;      // указатель на double
char*        pc;      // указатель на char
int**        ppi;     // указатель на указатель на int
int*         arr[10]; // массив из 10 указателей на int
int (*parr)[10];      // указатель на массив из 10 int
int (*pf)(int);       // указатель на функцию, принимающую int и возвращающую int
```

#### 1.3. Инициализация и nullptr

```cpp
int* p = nullptr;      // современный C++ (C++11)
int* q = NULL;         // старый C-стиль, лучше не использовать
int* r = 0;            // тоже работает, но неявно
```

Всегда инициализируйте указатели. Неинициализированный указатель содержит мусор — разыменование ведёт к неопределённому поведению (UB).

#### 1.4. Разыменование

```cpp
int x = 42;
int* p = &x;
std::cout << *p;   // 42
*p = 100;          // теперь x == 100
std::cout << x;    // 100
```

Разыменование `nullptr` или висячего указателя — UB, обычно segfault.

#### 1.5. Арифметика указателей

Указатель можно двигать. Шаг зависит от размера типа:

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* p = arr;      // arr распадается в &arr[0]
std::cout << *p;      // 10
std::cout << *(p+1);  // 20
p++;                  // теперь указывает на arr[1]
std::cout << *p;      // 20
// Разница указателей — количество элементов между ними
int* a = &arr[0];
int* b = &arr[4];
std::cout << (b - a);  // 4
```

Размер шага:

```cpp
int* pi;       // pi+1 сдвигает на 4 байта
double* pd;    // pd+1 сдвигает на 8 байт
char* pc;      // pc+1 сдвигает на 1 байт
```

#### 1.6. Указатели и const

Четыре комбинации, важно понимать разницу:

```cpp
int x = 10;
int y = 20;
// 1. Указатель на const int: значение нельзя менять через указатель
const int* p1 = &x;
// *p1 = 5;    // ошибка
p1 = &y;       // ок, сам указатель можно менять
// 2. Const указатель на int: нельзя менять сам указатель
int* const p2 = &x;
*p2 = 5;       // ок
// p2 = &y;    // ошибка
// 3. Const указатель на const int: нельзя ни то, ни другое
const int* const p3 = &x;
// *p3 = 5;    // ошибка
// p3 = &y;    // ошибка
// 4. Обычный указатель
int* p4 = &x;
*p4 = 5;
p4 = &y;
```

Читайте справа налево: `const int* p` — «p — указатель на int, который const». `int* const p` — «p — const указатель на int».

#### 1.7. Указатели и массивы

Массив при передаче в функцию **распадается в указатель на первый элемент**:

```cpp
void f(int* arr, size_t n) {
    for (size_t i = 0; i < n; ++i)
        std::cout << arr[i] << " ";
}
int a[5] = {1,2,3,4,5};
f(a, 5);   // a распадается в int*
```

`arr[i]` — синтаксический сахар для `*(arr + i)`.

Размер массива внутри функции не узнать:

```cpp
void f(int arr[]) {
    // sizeof(arr) == 8, это размер указателя, а не массива!
}
```

Поэтому размер передают отдельно или используют `std::vector`, `std::array`, `std::span` (C++20).

#### 1.8. Указатели на функции


```cpp
int add(int a, int b) { return a + b; }
int (*op)(int, int) = &add;   // & необязателен
std::cout << op(2, 3);        // 5
```

Удобно для callbacks:

```cpp
void process(std::vector<int>& v, int (*transform)(int)) {
    for (auto& x : v) x = transform(x);
}
```

### 1.9. Указатели и динамическая память


```cpp
int* p = new int(42);         // один int
int* arr = new int[10];       // массив
// ...
delete p;                     // освободить один
delete[] arr;                 // освободить массив
```

Правила:

- `new` сочетается с `delete`;
- `new[]` сочетается с `delete[]`;
- не смешивайте;
- в современном C++ используйте `std::unique_ptr` / `std::shared_ptr` вместо ручного `new/delete`.

### Часть 2. Ссылки

#### 2.1. Что такое ссылка

Ссылка — это **псевдоним** для существующей переменной. Она не хранит адрес отдельно (обычно реализуется через указатель внутри, но семантически — это другое имя объекта).

```cpp
int x = 42;
int& ref = x;   // ref — другое имя для x
ref = 100;      // x теперь 100
std::cout << x; // 100
```

Ключевые отличия от указателя:

- ссылку **нельзя** переприсвоить на другой объект;
- ссылка **не может** быть «пустой» (нет `nullptr`);
- ссылка **обязана** быть инициализирована при объявлении;
- у ссылки нет «адреса ссылки» — `&ref` даёт адрес объекта, на который она ссылается.


```cpp
int a = 1, b = 2;
int& r = a;
r = b;       // это НЕ перепривязка, это a = b, т.е. a становится 2
// теперь a == 2, b == 2, r всё ещё ссылается на a
```

#### 2.2. Объявление ссылок


```cpp
int x = 10;
int& r = x;         // ссылка на int
const int& cr = x;  // const-ссылка
double d = 3.14;
double& dr = d;
```

#### 2.3. Const-ссылки

Позволяют читать объект, но не менять:

```cpp
int x = 10;
const int& cr = x;
// cr = 5;    // ошибка
std::cout << cr;  // ок
```


Особое свойство: const-ссылка может продлить жизнь временного объекта:

```cpp
const std::string& s = std::string("hello");  // временный объект живёт столько же, сколько s
```


Обычная ссылка на временный объект — ошибка:

```cpp
std::string& s = std::string("hello");  // ошибка компиляции
```

### 2.4. Rvalue-ссылки (C++11)


```cpp
int&& rr = 42;             // rvalue-ссылка на временный int
std::string&& s = std::string("hi");
```

Используются для move-семантики и perfect forwarding. Основы:


```cpp
void f(int&);    // lvalue-ссылка: принимает именованные объекты
void f(int&&);   // rvalue-ссылка: принимает временные
int x = 1;
f(x);            // int&
f(42);           // int&&
f(std::move(x)); // int&& — явно кастуем к rvalue
```

### Часть 3. Передача в функции

#### 3.1. По значению

```cpp
void f(int x) { x = 100; }   // копия, оригинал не меняется
```

Копия создаётся. Для больших объектов дорого.

#### 3.2. По указателю

```cpp
void f(int* p) {
    if (p) *p = 100;   // проверка на nullptr обязательна
}
int x = 1;
f(&x);   // x станет 100
f(nullptr);  // безопасно, если внутри проверка
```

Плюсы: можно передать «ничего» (`nullptr`), можно менять указатель.  
Минусы: нужно проверять на nullptr, синтаксис с `*` и `&`.

#### 3.3. По ссылке

```cpp
void f(int& r) { r = 100; }   // меняет оригинал
int x = 1;
f(x);   // x == 100
```

Плюсы: нет копии, не нужно проверять на nullptr, чистый синтаксис.  
Минусы: нельзя передать «ничего» (нет аналога nullptr), нельзя передавать временный string.

#### 3.4. По const-ссылке

```cpp
void print(const std::string& s) {
    std::cout << s;   // читаем, но не меняем
}
std::string big = "...";
print(big);           // без копии
print("literal");     // работает: временный string создаётся и продлевается
```

Это **предпочтительный способ** передавать большие объекты только для чтения.

#### 3.5. По rvalue-ссылке

```cpp
void consume(std::string&& s) {
    std::string local = std::move(s);  // забираем ресурсы
}
```

Для move-семантики. Обычно используется в перегрузках `const T&` и `T&&`.

#### 3.6. Правила выбора

|Ситуация|Как передавать|
|---|---|
|Малый тип (int, double, указатель)|по значению|
|Большой объект только для чтения|`const T&`|
|Большой объект с изменением|`T&`|
|Нужна возможность «ничего»|`T*` (или `std::optional<T&>` в C++26)|
|Перемещение/забор ресурсов|`T&&` + `std::move`|
|Шаблон с perfect forwarding|`T&&` + `std::forward<T>`|

#### 3.7. Возврат из функций

```cpp
int* f1() { int x = 5; return &x; }        // ОШИБКА: возврат адреса локальной переменной
int& f2() { int x = 5; return x; }         // ОШИБКА: то же самое
int* f3(int* p) { return p; }              // ок, если p жив
int& f4(int& r) { return r; }              // ок, если объект жив
```

Возвращать ссылку/указатель на локальную переменную — UB.

Можно возвращать ссылку на статическую, глобальную или переданную снаружи переменную:

```cpp
int& at(std::vector<int>& v, size_t i) { return v[i]; }  // ок
```

### Часть 4. Структуры

#### 4.1. Объявление

```cpp
struct Point {
    double x;
    double y;
};
```

В C++ (в отличие от C) `struct` — это полноценный тип, не нужно писать `struct Point p;` — достаточно `Point p;`.

#### 4.2. Создание и доступ

```cpp
Point p1;                  // поля не инициализированы (мусор)
Point p2{1.0, 2.0};        // aggregate initialization
Point p3 = {1.0, 2.0};     // то же
Point p4{};                // все поля = 0
p2.x = 5.0;
std::cout << p2.x << ", " << p2.y;
```

#### 4.3. Указатель на структуру

```cpp
Point p{1.0, 2.0};
Point* ptr = &p;
// Три эквивалентных способа доступа:
(*ptr).x = 10.0;   // разыменование + точка
ptr->x = 10.0;     // стрелка — то же самое, удобнее
ptr[0].x = 10.0;   // если ptr указывает на первый элемент массива
```

Оператор `->` — это сахар для `(*ptr).member`.

#### 4.4. Ссылка на структуру

```cpp
Point p{1.0, 2.0};
Point& ref = p;
ref.x = 10.0;      // меняет p
```

Ссылка использует обычную точку, потому что семантически это тот же объект.

#### 4.5. Передача структуры в функцию

```cpp
struct Big {
    int data[1000];
};
void byValue(Big b);              // копия 4000 байт — плохо
void byPointer(Big* b);           // 8 байт, но нужна проверка и ->
void byReference(Big& b);         // 8 байт, синтаксис с точкой
void byConstRef(const Big& b);    // 8 байт, только чтение — лучший вариант
```

#### 4.6. Вложенные структуры

```cpp
struct Address {
    std::string city;
    std::string street;
};
struct Person {
    std::string name;
    Address addr;      // вложенная по значению
    Address* work;     // или указатель
};
Person p;
p.addr.city = "Moscow";
p.work = new Address{...};
```

#### 4.7. Методы в структурах

В C++ `struct` и `class` отличаются только доступом по умолчанию: у `struct` всё `public`, у `class` — `private`. В остальном они эквивалентны.

```cpp
struct Point {
    double x = 0;
    double y = 0;
    double length() const {
        return std::sqrt(x*x + y*y);
    }
    void move(double dx, double dy) {
        x += dx;
        y += dy;
    }
};
Point p{3, 4};
std::cout << p.length();  // 5
p.move(1, 1);
```

`const` после метода означает, что метод не меняет поля объекта.

#### 4.8. Конструкторы и деструкторы

```cpp
struct Point {
    double x, y;
    Point() : x(0), y(0) {}                       // конструктор по умолчанию
    Point(double x_, double y_) : x(x_), y(y_) {} // параметризованный
    ~Point() {}                                    // деструктор
    // Конструктор копирования
    Point(const Point& other) : x(other.x), y(other.y) {}
    // Оператор присваивания
    Point& operator=(const Point& other) {
        if (this != &other) {
            x = other.x;
            y = other.y;
        }
        return *this;
    }
};

```
`this` — указатель на текущий объект. Внутри метода `x` — то же самое, что `this->x`.

#### 4.9. Структуры и указатели в динамической памяти

```cpp
// Один объект
Point* p = new Point{1.0, 2.0};
std::cout << p->x;
delete p;
// Массив объектов
Point* arr = new Point[10];
arr[3].x = 5.0;      // или (arr + 3)->x = 5.0;
delete[] arr;
```

Современный C++:


```cpp
auto p = std::make_unique<Point>(1.0, 2.0);
p->x = 5.0;
// delete не нужен, unique_ptr сам освободит
auto arr = std::make_unique<Point[]>(10);
arr[3].x = 5.0;
```

#### 4.10. Структуры и const


```cpp
struct Point { double x, y; };
Point p{1, 2};
const Point cp{3, 4};
Point* ptr = &p;             // ок
ptr->x = 10;                 // ок
const Point* cptr = &cp;     // указатель на const
// cptr->x = 10;             // ошибка
cptr = &p;                   // ок, сам указатель не const
Point* const cptr2 = &p;     // const указатель
cptr2->x = 10;               // ок
// cptr2 = &cp;              // ошибка
```

#### 4.11. Выравнивание и padding

Поля структуры выравниваются по своим размерам, поэтому между ними могут быть «дырки»:

```cpp
struct A {
    char c;    // 1 байт + 3 padding
    int i;     // 4 байта
};             // sizeof(A) == 8, не 5
struct B {
    int i;     // 4 байта
    char c;    // 1 байт + 3 padding
};             // sizeof(B) == 8
struct C {
    char c;    // 1
    int i;     // 4
    char c2;   // 1 + 3 padding
};             // sizeof(C) == 12
```

Порядок полей влияет на размер. Иногда имеет смысл переставлять поля для экономии памяти.

Управление выравниванием:

```cpp
#pragma pack(push, 1)
struct Packed {
    char c;
    int i;
};  // sizeof == 5, без padding
#pragma pack(pop)
```

Но это замедляет доступ и может быть запрещено на некоторых архитектурах.

### Часть 5. Указатель vs ссылка: сводная таблица

|Свойство|Указатель|Ссылка|
|---|---|---|
|Может быть nullptr|Да|Нет|
|Можно переприсвоить|Да|Нет|
|Обязательна инициализация|Нет|Да|
|Своя память|Да (8 байт)|Обычно нет (псевдоним)|
|Арифметика|Да|Нет|
|Синтаксис доступа|`*p`, `p->x`|`.`, напрямую|
|Массив указателей|Да|Массив ссылок — нельзя|
|Указатель на указатель|Да|Ссылка на ссылку — нельзя|
|`const`-варианты|4 комбинации|`const T&`|
|Когда использовать|Опциональность, арифметика, C API|Обычная передача, возврат из операторов|

### Часть 6. Частые ошибки и как их избегать

#### 6.1. Висячий указатель


```cpp
int* f() {
    int x = 5;
    return &x;   // x умрёт при выходе, указатель станет висячим
}
int* p = new int(5);
delete p;
std::cout << *p;  // UB: use-after-free
```

#### 6.2. Утечка памяти

```cpp
void f() {
    int* p = new int(5);
    // забыли delete
}
```

Решение: RAII, `std::unique_ptr`, `std::shared_ptr`.

#### 6.3. Двойное освобождение

```cpp
int* p = new int(5);
delete p;
delete p;   // UB
```

#### 6.4. Разыменование nullptr

```cpp
int* p = nullptr;
*p = 5;   // segfault
```

Всегда проверяйте, если указатель может быть пустым.

#### 6.5. Возврат ссылки на локальную переменную

```cpp
int& f() {
    int x = 5;
    return x;  // UB
}
```

#### 6.6. Смешение new/delete и new[]/delete[]

```cpp
int* p = new int[10];
delete p;      // UB, нужно delete[]
```

#### 6.7. Ссылка на временный объект

```cpp
int& f() { return 42; }   // ошибка компиляции
```

### Часть 7. Современные альтернативы

C++11 и позже добавили инструменты, которые уменьшают потребность в сырых указателях:


```cpp
std::unique_ptr<T>    // единоличное владение
std::shared_ptr<T>    // разделяемое владение
std::weak_ptr<T>      // слабая ссылка на shared
std::optional<T>      // значение или ничего
std::reference_wrapper<T>  // ссылка, которую можно копировать и хранить в контейнерах
std::span<T>          // view на массив (C++20)
std::string_view      // view на строку (C++17)
```

Пример:

```cpp
// Вместо int* с ручным delete
auto p = std::make_unique<int>(42);
// Вместо передачи (T* ptr, size_t n)
void f(std::span<int> data);
// Вместо const std::string& с риском временного объекта
void f(std::string_view s);
```

### Итог

1. **Указатель** — адрес. Может быть nullptr, можно двигать, можно переприсваивать.
    
2. **Ссылка** — псевдоним. Не может быть nullptr, нельзя переприсвоить, обязана быть инициализирована.
    
3. **Структура** — набор полей; в C++ это полноценный тип с методами, конструкторами, наследованием.
    
4. **Передача**: малые типы — по значению; большие для чтения — `const T&`; большие для изменения — `T&`; опциональные — `T*`; перемещение — `T&&`.
    
5. **Владение** — ключевое понятие. В современном C++ предпочитайте `unique_ptr`/`shared_ptr` сырым `new/delete`.
    
6. **Ошибки** чаще всего связаны с временем жизни: висячие указатели, утечки, двойное освобождение, возврат ссылок на локальные объекты.
