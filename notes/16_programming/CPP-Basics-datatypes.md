### Чем `char buf[1024]` отличается от `char* msg="Hello"`

`char* msg = "Hello";` — Указатель на константную строку

- **Где хранятся данные:** Сама строка `"Hello"` компилятором записывается в секцию **`.rdata`** (Read-Only Data) исполняемого файла. Это область памяти, предназначенная исключительно для чтения.
- **Где хранится переменная:** Переменная `msg` — это обычный **указатель** (ячейка размером 8 байт на 64-битной системе), которая лежит на стеке. Внутри этой ячейки записан адрес памяти, ведущий в ту самую защищенную секцию `.rdata`.
- **Что можно и нельзя делать:**
    - Вы можете в любой момент перенаправить указатель на другую строку: `msg = "World";` (указатель просто начнет смотреть на другой адрес в `.rdata`).
    - **Нельзя изменять символы!** Если вы попытаетесь написать `msg[0] = 'M';`, программа мгновенно упадет в Runtime с ошибкой **Segmentation Fault**. Операционная система на аппаратном уровне защищает секцию `.rdata` от записи.


`char buf[1024] = "Hello";` — Выделение массива на стеке

- **Где хранятся данные:** Компилятор выделяет ровно 1024 байта непрерывной памяти **прямо на стеке** текущей функции (внутри памяти вашего процесса).
- **Как это работает под капотом:** При запуске функции ядро выделяет 1024 байта «чистой» памяти, а затем физически копирует туда буквы `'H'`, `'e'`, `'l'`, `'l'`, `'o'`, `'\0'`.
- **Что можно и нельзя делать:**
    - **Можно спокойно изменять символы:** Строка `buf[0] = 'M';` сработает идеально, и слово превратится в `"Mello"`, потому что эта память принадлежит вашей функции, и она открыта для записи.
    - **Нельзя переприсвоить массив целиком:** Вы не можете написать `buf = "World";` после объявления. Массив жестко «прибит» к своему месту на стеке. Изменить его содержимое можно только посимвольно или через функцию `strcpy`.


1. **В случае с массивом (`char buf[1024]`)**: Переменная `buf` — это **не самостоятельная ячейка памяти**. `buf` — это просто текстовая метка (имя) для куска памяти размером 1024 байта. У этой метки нет своего собственного адреса, она сама и есть этот кусок.
2. **В случае с указателем (`char* msg`)**: Переменная `msg` — это **реальный физический объект** (8 байт), у которого есть свой собственный адрес на стеке, и внутри которого лежит _чужой_ адрес строки из `.rdata`.
